# Asset provenance

All photographic assets were generated with the built-in image generation tool for this assessment, then resized and JPEG-compressed for delivery. No reference screenshot fragments are used as UI assets. No remote media requests are needed.

Files are in `assets/images/`. `hero.jpg` is the mobile photograph; `hero-v2.jpg` is the refined desktop photograph. Food assets range from about 110–375KB; portraits are 128px thumbnails. Customer portraits depict fictional demo people and do not verify the supplied testimonial copy.

Lora and DM Sans are bundled by their `@expo-google-fonts` packages under the SIL Open Font License. License copies are in `docs/licenses/`. Lucide icons use the ISC license. The text-based Arabic-style Healthify mark approximates the supplied logo. The botanical outline and leaf favicon were created in code.
